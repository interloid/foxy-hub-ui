# Foxy Hub | Agency Client Portal

Foxy Hub is a multi-tenant agency client portal, project management, and billing platform designed to streamline operations between agencies and their clients. Built with a modern, high-performance tech stack.

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Server Components)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Theme Management:** [next-themes](https://github.com/pacocoursey/next-themes) (Light / Dark / System support)
- **Backend & Database:** Supabase _(Planned/Configured)_
- **Language:** TypeScript

---

## 🛠️ Getting Started

### Prerequisites

Ensure you have the following installed on your local machine:

- **Node.js** (v18+ recommended)
- **npm** or **pnpm**

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/foxy-hub-ui.git](https://github.com/your-username/foxy-hub-ui.git)
   cd foxy-hub-ui
   ```
